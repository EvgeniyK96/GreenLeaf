# GreenLeaf: React, 3D и анимации

Перед началом загрузи навык `frontend-design` и следуй ему, чтобы страница не выглядела шаблонной.

## Входные данные
`content/copy.md`, `content/facts.md`, `CLAUDE.md`, `PLAN.md`. Изображения клиента лежат в `assets/src/`.

## Стек и структура
Vite + React 18+ + TypeScript. Зависимости: `three`, `@react-three/fiber`, `@react-three/drei`, `motion`, при необходимости `gsap` (ScrollTrigger) и `lenis` для плавного скролла.
```
src/
  main.tsx  App.tsx
  content/        (тексты и данные из copy.md: блоки, пакеты, бонусы, FAQ, товары)
  components/     (Hero, Facts, Paths, Calculator, Bonuses, Scale, Products, Packages, Steps, Stories, Faq, LeadForm, Legal)
  three/          (HeroScene, PackageCard3D, useGpuTier, Poster)
  hooks/          (useReducedMotion, useInView)
  styles/         (tokens.css: переменные цветов, шрифтов, отступов)
public/  (WebP, logo, постеры)
content/ (TODO.md, QA.md, COMPLIANCE.md)
```
Тексты и данные держи в `src/content/`, а не внутри компонентов: клиент должен менять ID, контакты и цены в одном месте.

## 3D (three.js)
- **Hero-сцена:** процедурные листья (параметрическая геометрия или `InstancedMesh` из 30–60 штук), мягкий зелёный свет, лёгкое покачивание, реакция на курсор и скролл. Без тяжёлых моделей и текстур.
- **Акценты:** (1) 3D-карточки пакетов, которые слегка поворачиваются при наведении; (2) визуал "роста" в блоке плана вознаграждения, привязанный к скроллу. Не больше 3 канвасов на страницу, один `Canvas` на секцию, остальные скрыты при выходе из вьюпорта.
- **Производительность:** `React.lazy` + `Suspense` для всех 3D-компонентов, `dpr={[1, 1.5]}`, `frameloop="demand"` там, где нет постоянной анимации, `useGpuTier` (или `navigator.hardwareConcurrency` и ширина экрана) для деградации.
- **Фолбэк:** на слабых устройствах, без WebGL и при `prefers-reduced-motion` вместо канваса рендерится `Poster` (WebP или CSS-градиент с листьями). Страница полностью работает без 3D.
- Освобождай ресурсы (`dispose`) при размонтировании.

## Анимации интерфейса
- `motion`: появление блоков при скролле (`whileInView`, `once: true`), счётчики цифр, анимация раскрытия аккордеонов, переходы в калькуляторе.
- Параллакс только у фото и декоративных элементов, не у текста.
- Все анимации короткие (200–600 мс), с одним набором easing в `tokens.css`. При `prefers-reduced-motion` анимации выключаются или упрощаются.

## Дизайн
- Палитра из черновика: белый и светло-зелёный фон, бренд-зелёный `#2b7a4b`, один акцент для CTA. Всё в CSS-переменных.
- Шрифт: один, подключённый локально или с `font-display: swap`. Читаемый кириллический.
- Mobile first. Липкая кнопка "Написать" и пара CTA в hero. Тап-зоны ≥ 44 px.
- Фото только из `assets/src/`. Нет фото → аккуратная заглушка и пункт в `content/TODO.md`.

## Функциональность
1. **Калькулятор выгоды.** Поле "трачу в месяц на уход и быт" → экономия = сумма × 0,5 (разница розница/партнёр из каталога). Подпись: "расчёт экономии по прайсу, не доход". Коэффициент в константе, проверь на 3–4 позициях каталога. Результат анимированно «досчитывается».
2. **Аккордеоны:** 11 бонусов в 3 группах, пакеты, FAQ. Доступны с клавиатуры (`button`, `aria-expanded`).
3. **Форма заявки:** имя, мессенджер/телефон, город, интерес, выбор "встреча / регистрация по ID", чекбокс согласия с политикой. Отправка на `VITE_FORM_ENDPOINT` (или `mailto:`/Telegram-ссылка как запасной вариант). Honeypot, защита от двойной отправки, состояния загрузки/успеха/ошибки. Никаких токенов в клиентском коде.
4. **Копирование ID:** кнопка копирует ID из `src/content`, показывает подтверждение.
5. **Плейсхолдеры:** если значение `{{...}}` не заполнено, в режиме разработки выводится заметная пометка, а пункт записывается в `content/TODO.md`.

## Качество
- Семантическая разметка, `alt`, контраст AA, фокус виден, навигация с клавиатуры.
- `npm run build` без ошибок и предупреждений TypeScript/ESLint.
- Lighthouse mobile: Performance ≥ 85 (с 3D), Accessibility ≥ 95. Проверь размер чанка three.js (< 200 КБ gzip) через анализ сборки.
- Проверь в браузере на 360, 768, 1280 px, с включённым и выключенным 3D (эмулируй `prefers-reduced-motion`). Результаты запиши в `content/QA.md`.
- Сборка должна открываться локально (`npm run dev`, `npm run preview`) и быть готова к деплою на Vercel или любой статический хостинг.
