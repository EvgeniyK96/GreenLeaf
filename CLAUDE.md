# Проект: лендинг партнёрской программы GreenLeaf Family

Язык интерфейса и текстов: **русский**. Аудитория: потенциальные партнёры в России и СНГ, в основном с телефона.

## Цель страницы
Один из двух шагов: (A) встреча в городе владельца страницы, (B) регистрация у себя в городе под ID владельца. Все CTA ведут к одному из них.

## Жёсткие правила
1. Никаких обещаний дохода и "типовых" заработков. Пишем условия начисления и расчёт экономии по прайсу.
2. Неизвестные данные (ID, контакты, город, цифры масштаба) = явные плейсхолдеры `{{...}}` и список в `TODO.md`. Не заполнять догадками.
3. Не называть модель "франшизой". Использовать "партнёрская программа", "бизнес-место".
4. Нет вымышленных отзывов и кейсов. Блок историй остаётся скрытым, пока нет реальных материалов.
5. Форма: честное согласие на обработку данных, антиспам, без хранения секретов в клиентском коде.
6. Стек: Vite + React + TypeScript. 3D: three.js через `@react-three/fiber` и `@react-three/drei`. Анимации интерфейса и скролла: `motion` (Framer Motion) и/или GSAP + ScrollTrigger. Стили: CSS Modules или Tailwind, цвета в переменных.
7. Анимации служат продаже, а не украшению: 3D только в hero и 1–2 акцентных блоках, остальное лёгкие анимации появления. Тяжёлое грузится лениво (`React.lazy`, `Suspense`), на слабых устройствах и при `prefers-reduced-motion` вместо 3D показывается статичный постер. Весь контент читается и кликается без 3D.
8. Производительность: Lighthouse mobile ≥ 85 (с 3D), первый экран виден < 2,5 с, чанк three.js < 200 КБ gzip через code splitting, изображения WebP.
