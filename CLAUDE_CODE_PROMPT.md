# Промт для Claude Code (React + three.js)

Скопируйте блок ниже в Claude Code, запущенный в папке `greenleaf-landing` (рядом лежат `CLAUDE.md`, `PLAN.md` и `.claude/skills/`).

```
Ты делаешь лендинг партнёрской программы GreenLeaf Family для клиента (владельца страницы, который приглашает партнёров).
Сначала прочитай CLAUDE.md и PLAN.md: они задают цель, факты, правила, стек и структуру блоков.

Контекст
- Цель страницы: посетитель выбирает (A) встречу в городе владельца или (B) регистрацию у себя в городе под ID владельца.
- Аудитория: люди в России и СНГ, в основном с телефона, без опыта в сетевых моделях.
- Тема специфическая, поэтому страница должна объяснить выгоду, пользу, перспективу и ответить на вопрос "за что компания платит".
- Черновик прошлого исполнителя не нравится (справочник без мотивации). Из него берём только палитру и фактические данные.

Стек (обязательно)
- Vite + React + TypeScript.
- 3D: three.js через @react-three/fiber и @react-three/drei.
- Анимации: motion (Framer Motion) для интерфейса и появления блоков, при необходимости GSAP ScrollTrigger и lenis.
- Стили: CSS Modules или Tailwind, цвета и отступы в переменных.

Порядок выполнения
1. Открой и изучи:
   - https://funky.31-220-74-177.sslip.io/vps2/greenleaf-mila-0611/a/index.html (структура, палитра, пакеты, 11 выплат, ссылки на PDF плана),
   - https://greenleaf-company.ru/catalog/zdorove (цены розница/партнёр и PV, 66 позиций в разделе).
   Скачай PDF маркетингового плана и прочитай страницы 2–15 через навык pdf-reading.
2. Запиши проверенные факты в content/facts.md (источник рядом с каждым фактом).
3. Навык greenleaf-copy: напиши content/copy.md по 14 блокам из PLAN.md.
4. Создай проект: npm create vite@latest (react-ts), установи three, @react-three/fiber, @react-three/drei, motion. Вынеси тексты и данные в src/content/.
5. Навык greenleaf-build (вместе с frontend-design): собери компоненты по блокам, 3D-сцену hero (процедурные листья и частицы, реакция на курсор и скролл), 1–2 акцентных 3D/scroll-момента, калькулятор выгоды, аккордеоны, форму, кнопку копирования ID.
6. 3D делай аккуратно: ленивая загрузка, фолбэк-постер для слабых устройств и prefers-reduced-motion, не больше 3 канвасов, страница полностью работает без 3D.
7. Навык greenleaf-compliance: проверь тексты и факты, исправь, оформи content/COMPLIANCE.md.
8. Запусти npm run build и npm run preview, проверь в браузере на 360, 768, 1280 px с 3D и без. Замерь Lighthouse mobile и размер чанка three.js. Исправь дефекты, результаты запиши в content/QA.md.
9. Собери content/TODO.md: неизвестные данные, плейсхолдеры, нужные от клиента материалы.

Жёсткие правила
- Никаких обещаний и "типовых" доходов. Только условия плана и расчёт экономии по прайсу.
- Ничего не выдумывай: ID, контакты, город, цифры масштаба, отзывы, фото. Нет данных = плейсхолдер и пункт в TODO.md.
- Не называй модель "франшизой", используй "партнёрская программа" и "бизнес-место".
- Не копируй код и тексты черновика, переписывай своими словами.
- Анимации работают на продажу: не закрывай ими текст и CTA, не замедляй первый экран.
- Тексты на русском, тон: уверенный, дружелюбный, конкретный.

Результат
Работающий React-проект (npm run dev / build / preview), готовый к деплою на Vercel, плюс content/COMPLIANCE.md, content/QA.md, content/TODO.md.
В конце коротко отчитайся: что сделано, что не хватает от клиента, какие решения принял сам, показатели Lighthouse.
```

## Как запускать
1. `cd greenleaf-landing`
2. `claude`
3. Вставить блок выше. Скилы подхватятся автоматически из `.claude/skills/`.
4. После первого прогона показать клиенту hero с 3D и 2–3 блока, затем доводить по замечаниям.
