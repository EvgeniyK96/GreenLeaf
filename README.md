# GreenLeaf Family — лендинг партнёрской программы

Vite + React 19 + TypeScript, 3D на three.js (`@react-three/fiber`, `@react-three/drei`), анимации — `motion`. Стили — CSS Modules, все цвета и отступы в `src/styles/tokens.css`.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:5173 (незаполненные данные подсвечены жёлтым)
npm run build      # сборка в dist/ + пререндер HTML + отчёт о незаполненных данных
npm run preview    # просмотр сборки: http://localhost:4173
npm run build:release  # то же, но падает, если остались {{плейсхолдеры}}
npm run check:content  # только список незаполненных данных
npm run lint           # oxlint
```

## Где менять данные

Все тексты и цифры — в `src/content/`, в компонентах их нет:

| Файл | Что внутри |
|---|---|
| `owner.ts` | **ID, город, Telegram, WhatsApp, телефон, срок ответа, данные оператора ПДн** |
| `copy.ts` | тексты блоков, факты масштаба, фото, расписание |
| `bonuses.ts` | 11 видов начислений по маркетинговому плану |
| `packages.ts` | стартовые наборы (бизнес-места) |
| `products.ts` | товары с ценами из каталога |
| `faq.ts` | вопросы и ответы |
| `stories.ts` | истории партнёров — блок появится, когда массив не пуст |
| `site.ts` | ссылки, даты прайса и плана, коэффициент калькулятора (0,5) |

Значение вида `{{KEY}}` = не заполнено. Полный список и что нужно от клиента — `content/TODO.md`. Политика и согласие — `public/privacy.html`, `public/consent.html`.

## Переменные окружения

| Переменная | Где | Зачем |
|---|---|---|
| `VITE_FORM_ENDPOINT` | сборка (клиент) | URL приёма заявок, например `/api/lead`. Без неё форма предлагает написать напрямую и собирает текст заявки |
| `VITE_SHOW_PLACEHOLDERS=true` | сборка | показать `{{ключи}}` и в продакшене (для показа клиенту) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | только Vercel → Environment Variables | доставка заявок функцией `api/lead.ts` |
| `ALLOWED_ORIGIN` | Vercel | принимать заявки только с вашего домена |

Секретов в клиентском коде нет. Пример — `.env.example`. Перед подключением Telegram прочитайте раздел про персональные данные в `content/COMPLIANCE.md`.

## Деплой на Vercel

Проект готов: `vercel.json` задаёт сборку (`npm run build`, папка `dist`), кэш и заголовки безопасности; функция `api/lead.ts` подхватится автоматически. Импортируйте репозиторий в Vercel или выполните `vercel` в папке проекта, затем задайте переменные окружения.

На любом статическом хостинге тоже работает (папка `dist/`), но тогда нужен свой обработчик заявок.

## 3D и производительность

- Первый экран — готовый HTML из пререндера и SVG-постер. three.js (≈188 КБ gzip) грузится лениво: по первому взаимодействию или через 3,5 с простоя.
- Без 3D (постер): `prefers-reduced-motion`, нет WebGL или он программный, ≤ 1 ядра или ≤ 1 ГБ памяти, экономия трафика, 2G. На 2–4 ядрах и телефонах — облегчённая сцена.
- 3D появляется не сразу: после первого движения мыши, касания или скролла (или само через 3,5 с). Если листьев нет — пошевелите мышью; если всё равно нет, откройте `?3d=on`: это значит, что браузер сообщает о программном WebGL или включено «уменьшение движения» в системе.
- Блоки ниже первого экрана гидрируются, когда подходят к экрану (`src/components/Island.tsx`).
- Параметры для проверки: `?3d=on`, `?3d=low`, `?3d=eager` (сразу после load), `?3d=off`.

Результаты Lighthouse и браузерных проверок — `content/QA.md`.
